# Design brief (from user refs)

## Brand
- Network: **RoyalCTW** (no “Iori Network”). Store/discord URLs por config.
- Alerts staff: cian/rosa/amarillo; sanciones modern: rojo/blanco/negro.

## Dual design
- **Modern 1.16+:** hex/gradients, MiniMessage, bossbars, menús lore “DUELOS [★]”, scoreboard Honly-style, ban screen con iconos.
- **Legacy 1.8.9–1.12:** `&` colors, PictureLogin head ASCII/MOTD, sin bossbar (o off), menús simples.
